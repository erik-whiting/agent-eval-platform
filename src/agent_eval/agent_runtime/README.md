# Agent runtime

Offline runtime demonstrates scope routing, optional retrieval, and deterministic RNA metrics. It receives AgentInput without references. It is a runnable wiring example, not a model agent. Implement a LangGraph runtime against the same contract and retain this runtime for smoke tests.

## Extension contract

Keep provider-specific code behind the shared interfaces in `core/models.py`. Add focused tests for behavior before enabling an experimental configuration. See the top-level README and research_questions.md for experiment boundaries.
